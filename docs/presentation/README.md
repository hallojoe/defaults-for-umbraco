# Umbraco 17 / Aspire presentation

The deck is a local [Slidev](https://sli.dev/) project. Individual slides live in `slides/`; `slides.md` imports them in presentation order.

```powershell
cd docs/presentation
npm install
npm run dev
```

Use `npm run build` to create a static site in `dist`, or `npm run export` to export the deck.
